Privacy Policy

Calm Cascade Uploader · last updated 9 November 2026

Calm Cascade Uploader is a private tool used only by the owner of the Calm Cascades YouTube channel to upload and schedule that channel's own videos. It is run by Exilien (eugene@exilien.co). It is not offered to the public and has no other users.

What it accesses

With the channel owner's permission, the tool uses the YouTube Data API to:

  • upload videos and thumbnails to the Calm Cascades channel, and set their title, description, tags and publish time;
  • read the signed-in channel's name and ID, to confirm it is uploading to the right channel.

What it stores

The only data kept is the sign-in token Google issues, stored on the owner's own computer so that uploads can run without signing in each time. No YouTube data, viewer data or personal data is collected, sold, shared or sent anywhere else.

YouTube and Google

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be revoked at any time from Google account permissions. Revoking it, or deleting the stored token, removes the tool's access straight away.
